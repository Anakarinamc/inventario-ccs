# Inventario Caracas

App de inventario del almacén de Caracas. Es una sola página (`index.html`) publicada como artifact de Claude; los datos (catálogo, conteos, compras pendientes) viven en la base de datos del artifact, no en este repositorio.

- `index.html`: código de la app tal como está publicada.
- Para cambiar la app: editar `index.html`, publicar en el mismo artifact y guardar aquí el cambio.

- En esta copia los IDs de las hojas de Google están reemplazados por marcadores (`ID_SHEET_...`). Los IDs reales solo están en la versión publicada.
